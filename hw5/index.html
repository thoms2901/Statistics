Exercise 1. Welford's recurrence formulas

1.1 Knuth's recurrence for the mean

Let Mk = (x1 + … + xk)/k. Then kMk = (k−1)Mk−1 + xk, and dividing by k:

M_k = M_{k-1} + (x_k - M_{k-1}) / k M_1 = x_1

The new mean is the old mean plus 1/k of the difference between the new value and the old mean. There is no running sum, so the numbers involved do not grow with k.

1.2 Recurrence for the sum of squares

Define SSk = Σi≤k (xi − Mk)², the sum of squared deviations from the current mean. Expanding the square gives the textbook identity SSk = Σ xi² − k Mk², so

SS_k - SS_{k-1} = x_k^2 - k M_k^2 + (k-1) M_{k-1}^2 write M = M_{k-1}, d = x_k - M, so x_k = M + d and M_k = M + d/k (Knuth): x_k^2 = M^2 + 2Md + d^2 k M_k^2 = k M^2 + 2Md + d^2/k (k-1) M_{k-1}^2 = (k-1) M^2 SS_k - SS_{k-1} = M^2 + 2Md + d^2 - k M^2 - 2Md - d^2/k + (k-1) M^2 = d^2 (1 - 1/k) = d * d (k-1)/k and x_k - M_k = d - d/k = d (k-1)/k, hence SS_k = SS_{k-1} + (x_k - M_{k-1}) (x_k - M_k) SS_1 = 0

The increment is the deviation from the old mean times the deviation from the new mean. The two factors always have the same sign, so SS never decreases.

1.3 Recurrences for the variance

With the sample variance s²k = SSk/(k−1) and the population (biased) variance σ²k = SSk/k, substitute SSk and SSk−1:

(k-1) s_k^2 = (k-2) s_{k-1}^2 + (x_k - M_{k-1})(x_k - M_k) s_k^2 = s_{k-1}^2 + [ (x_k - M_{k-1})(x_k - M_k) - s_{k-1}^2 ] / (k-1) k >= 2, s_1^2 = 0 k sigma_k^2 = (k-1) sigma_{k-1}^2 + (x_k - M_{k-1})(x_k - M_k) sigma_k^2 = sigma_{k-1}^2 + [ (x_k - M_{k-1})(x_k - M_k) - sigma_{k-1}^2 ] / k

They have the same form as Knuth's formula: old value plus (new term − old value) divided by a weight. In the code it is simpler to update SS and divide only at the end.

1.4 Code

function welford(xs) { let k = 0, mean = 0, ss = 0; for (const x of xs) { k++; const d = x - mean; // 1. deviation from the old mean mean += d / k; // 2. Knuth: update the mean ss += d * (x - mean); // 3. Welford: old deviation times new deviation } return { n: k, mean: mean, ss: ss, sampleVar: ss / (k - 1), popVar: ss / k }; }

Why use it. The other one-pass formula, Σx² − (Σx)²/n, subtracts two large numbers that are almost equal. With "offset 1e9" the data become 109 + {4, 7, 13, 16}: the variance is still 30, but x² ≈ 1018 is too large to be stored exactly in a double, and the naive formula gives a wrong (even negative) result. Welford works with deviations from the current mean, which stay small. It also reads the data only once and uses constant memory, which is useful when the data arrive as a stream.

2.4 Conclusions

Mean. The average of the sample means is very close to μ for every n, even for n = 2. This is because the sample mean is an unbiased estimator: E[X̄] = μ.

Variance. The average of the sample variances is close to σ² when we divide SS by n−1. If we divide by n instead, the average is σ²(n−1)/n, which is too small; the difference is large for small n (at n = 2 half of σ² is missing) and disappears as n grows. The reason is that the deviations are computed from X̄, which is calculated from the same data, so they are a bit smaller than the deviations from μ. This is why the sample variance uses n−1 (Bessel's correction).

Effect of n. When each hacker attacks more systems, the averages do not change, but the sample means and sample variances of the single hackers are less spread out: their standard deviations decrease like 1/√n (Fig. 6). So a single hacker's estimate becomes more precise.

Why it is useful in inference. In practice we usually have only one sample, not m. The simulation shows what happens if we repeat the sampling many times: X̄ and s² are random variables centred on μ and σ², with a spread that decreases like 1/√n. This is what justifies using them as estimates of μ and σ², and the standard error s/√n is what we use to build confidence intervals and tests.
